# SonoPilot website

English multi-page project website for SonoPilot, a Vision-Language-Action robotic system for ultrasound-guided needle intervention.

## Pages

- Home
- Technology
- Validation
- Research & Open Science
- Translation
- Team

The site is intentionally dependency-free and deploys as static files through GitHub Pages. Editable links, metrics, publications, resources, and team data are centralized in `assets/js/content.js`.

## Local preview

Serve the repository root with any static file server. For example:

```sh
python3 -m http.server 4173
```

Then open `http://localhost:4173/`.

## Source and claim boundaries

Visible facts and project media are derived from the supplied SonoPilot presentation. Reported experimental results are explicitly labeled as experimental and are not presented as clinical-trial outcomes. The system is a research prototype and is not represented as an approved clinical product.
